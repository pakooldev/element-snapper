User Manual

Learn how to use Element Snapper in three simple steps.

1

Open the Extension

Click the Element Snapper icon in the Chrome toolbar to open the popup panel.

Tips & Notes

⌨️

Custom Shortcuts

Open Settings and find the Shortcuts section. Click any key combo to re-record it with your preferred hotkey.

⎋

Cancel Anytime

Press Esc to cancel any active selection mode and return to idle.

📐

Max Capture Size

The maximum capture size is 16,384 × 16,384 pixels — a browser hard limit.

🔒

Limitations

Cannot capture cross-origin iframes or Chrome system pages (chrome://).
