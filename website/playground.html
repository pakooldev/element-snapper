How to use this page

Open the popup (or the in-page panel via the toolbar icon) and try each mode against the boxes below. Element — click "Select Element" and hover any box. Area — drag a rectangle anywhere on the page. Screen — captures just what's visible right now. Page — captures this entire scrollable page, stitched together.
