# v1.5.1 (2026-09-23)

A polish release that fixes sticky headers and floating ads being duplicated in stitched captures, keeps the panel from disappearing when your history is empty, and makes the Output modes honest about what they can do.

### 🎨 Improvements

- **Area, Screen, and Page are disabled while Copy as Prompt is selected**: Copy as Prompt only produces text for a specific element you pick, so the other capture modes used to silently fall back to copying the image with no hint your chosen output was ignored. Those buttons are now greyed out while Copy as Prompt is active, with a hover tooltip explaining why.
- **Output toggle matches the website**: The Output toggle track in the floating panel no longer has its own lighter fill — it lets the panel background show through, the same as the toggle shown on the website.

### 🐛 Fixes

- **Sticky headers and floating ads no longer repeat down the image**: In a full-page or multi-tile capture, anything `position: fixed` or `sticky` (sticky navbars, cookie banners, chat widgets, floating ads) was captured into every single tile and stacked down the final screenshot. Those elements are now captured once, in the first tile where they naturally belong, and hidden for the rest.
- **The panel no longer vanishes on an empty history**: Clicking "View History" with nothing captured yet hid the floating panel in anticipation of a modal that never opened, so the extension looked like it had closed itself. The panel now only hides when a modal actually opens.
