# v1.5.0 (2026-09-17)

This release adds a "Copy as Prompt" output mode for pasting element context straight into AI coding tools, moves full-page capture back to a debugger-free engine, and polishes the floating panel with animated toggles and more reliable capture hygiene.

### ✨ New Features

- **"Copy as Prompt" output mode**: A new third Output option alongside Download and Copy Image. Pick it before selecting an element and the extension skips the screenshot entirely, instead copying a structured, Cursor-style text description (tag, role, selector, dimensions, text content, key styles) to your clipboard — handy for pasting into AI coding tools.
- **Remove All from capture history**: Clear your entire capture history in one click from the history modal, alongside the existing per-item remove.
- **Interactive playground page**: A new page on the website with live test targets (small, tall, wide, grid, and scrollable elements) for trying out every capture mode, including multi-tile stitching.

### 🎨 Improvements

- **Full-page capture no longer needs the debugger permission**: Full-page screenshots are back to the scroll-and-stitch method instead of Chrome's debugger API, so you won't see the "is debugging this browser" banner or be asked for that permission. A tiling bug that could cause 1px seams between columns is also fixed.
- **Sliding pill toggle animation**: The Format and Output toggles in the floating panel now animate with a smooth sliding pill instead of an instant color swap.
- **Color-coded hover highlights**: The dashed outline shown while selecting an element now uses a distinct color per output mode (green for Download, blue for Copy Image, purple for Copy as Prompt), so you can tell what a click will do before you click.

### 🐛 Fixes

- **Extension UI no longer appears in captures**: The floating panel, toast, and preview thumbnail are now reliably hidden before every capture and restored after, fixing a case where fast back-to-back captures could catch the UI in the shot.
- **Screen shortcut no longer conflicts with Mail**: The default keyboard shortcut for Screen capture changed from Cmd+Shift+I to Cmd+Shift+S, since the old default collided with a common mail-client shortcut.
