# v1.3.0 (2026-04-05)

This release introduces a persistent floating panel, configurable keyboard shortcuts, and click-and-drag area capture — a major expansion of how you can interact with the extension.

### ✨ New Features

- **Floating in-page panel**: A persistent, draggable panel is now injected directly into the page using Shadow DOM for full CSS isolation. Toggle it on and off via the extension icon — it stays open across captures without closing up like the popup does.
- **Configurable keyboard shortcuts**: Set your own keyboard shortcuts for each capture mode (Element, Area, Screen, Full Page) with per-OS safe defaults. Shortcuts can be enabled/disabled as a group, and a reset button restores defaults in one click.
- **Area capture (click-and-drag region selection)**: Draw a selection rectangle anywhere on the page to capture exactly the region you want. A live pixel-dimension label updates as you drag.

### 🎨 Improvements

- **Renamed and reordered action buttons**: Quick-action buttons are now labeled **Area**, **Screen**, and **Page** — more compact and consistent with common screenshot tool conventions.
- **Dot-only status indicator**: The status dot in the panel header has been simplified to a colored dot — no text label — for a cleaner, less cluttered header.
- **Close button and draggable header in settings**: You can now close the settings view via an × button, and the settings header is draggable so you can reposition the panel without reaching for the grip area.

### 🐛 Fixes

- **Keyboard shortcuts no longer show the panel**: Using the Screen or Page keyboard shortcuts now captures silently without flashing the floating panel. A `restorePanelAfterCapture` flag controls whether the panel should reappear — it does for button and element captures, but not for background shortcut captures.
- **Toast notification is now centered**: The capture-success/error toast was slightly off-center horizontally; it now aligns reliably to the middle of the viewport.
- **Clipboard toggle default mismatch on fresh install**: On a fresh install the service worker defaulted to download while the popup UI showed clipboard as enabled. Switched to nullish coalescing so both sides agree on clipboard-on as the default.
- **Duplicate countdown overlay**: A redundant `document.body.appendChild(overlay)` call in `showCountdownOverlay` was creating two countdown elements layered on top of each other; the duplicate has been removed.
